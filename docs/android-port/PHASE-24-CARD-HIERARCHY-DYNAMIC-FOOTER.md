# Android 移植阶段二十四：右侧卡片层级与动态底部控制栏

> 个人自用、仅技术验证，不对外分发。

## 右侧面板卡片层级

- 评论区卡片增加可见描边、1dp 阴影和更大圆角
- 评论卡片间距从 4dp 增加到 8dp
- 推荐 / 分集 / 投稿横向条目增加：
  - 白色卡片背景
  - 浅灰描边
  - 12dp 圆角
  - 1dp 阴影
  - 条目之间 8dp 间距
- 焦点态继续使用粉色边框和高亮背景

## 底部控制栏动态显示

底部按钮根据当前页面能力显示，不再固定六个：

- 首页：`X 刷新 / Y 搜索 / B 返回 / A 确定`
- 动态、我的、分类、直播：`X 刷新 / B 返回 / A 确定`
- 搜索页：`B 返回 / A 确定`
- 视频详情：`X 刷新窗口 / B 返回 / A 确定`

LA/RA 的视觉按钮已隐藏，避免占位；手柄 `LB/RB` 切换 Tab 的硬件映射继续保留。

## 验证

- 首页底部显示 4 个按钮
- 我的页底部显示 `X 刷新 / B 返回 / A 确定`
- 视频详情底部显示 `X 刷新 / B 返回 / A 确定`
- 详情页评论卡片描边和间距清晰
- 推荐列表每条为独立圆角卡片
- LB/RB 仍可切换详情页右侧 Tab
- 无 `FATAL EXCEPTION`
