# Android 移植阶段三十二：视频卡片更多菜单与全屏播放器增强

> 个人自用、仅技术验证，不对外分发。

## 1. 视频卡片长按与更多菜单

- 长按视频卡片弹出统一“视频操作”菜单。
- 卡片右上角新增可聚焦“⋮”更多按钮。
- 支持遥控器 `MENU` / `Y` 键打开菜单。
- 菜单项：
  - 播放视频
  - 进入详情页
  - 进入 UP 主主页
  - 添加到稍后再看
  - 分享
  - 不感兴趣/删除
  - 下载（卡片有 cid 且可播放时显示）
- 短按原有打开详情/播放逻辑保持不变。
- 动态、搜索、我的、首页、视频详情相关推荐等使用统一卡片的区域共用操作能力。
- Compact 横向视频行也接入长按菜单。
- 分享复用统一链接逻辑；下载复用 `DownloadRequestResolver` 和 `DownloadService`。

## 2. 全屏播放器视频数据

- 播放器设置新增“视频数据”入口。
- 实时显示：
  - 标题
  - BV/CID
  - 分辨率
  - 编码
  - 码率
  - 帧率
  - 画质 qn
  - 播放状态
  - 倍速
  - 当前/总时长
  - 缓冲位置和百分比
  - 渲染器
  - 解码器
  - 音轨/音频编码
  - CDN/线路
  - 列表来源
  - 丢帧和重缓冲次数
- 面板每 500ms 刷新。

## 3. 全屏播放器 DLNA

- 播放器设置新增“投屏（DLNA）”入口。
- 使用 SSDP 发现局域网 `MediaRenderer` 设备。
- 解析 `LOCATION`、`ST`、`USN`、`SERVER` 并去重。
- 无设备时提示检查同一局域网和 DLNA 开关。
- 发现设备后显示设备列表。
- 当前实现边界：仅完成设备发现，尚未集成 DLNA 媒体推送与播放控制；点击设备会明确提示当前版本无法投屏，不伪造成功。

## 4. 播放结束行为

- 播放模式为“什么都不做”：
  - 显示控制栏
  - 显示“播放结束 · 按确认重播”
- 单集循环：从头重播。
- 自动连播/分P/合集/推荐：保留原有倒计时逻辑。
- 自动退出：清理自动连播状态后退出播放器。
- 增加结束事件去重 key，离开 `ENDED` 状态后重置，避免重复触发。
- 确认重播时清理结束提示，避免旧提示残留。

## 验证

- 视频卡片长按成功弹出“视频操作”菜单。
- 菜单包含播放、详情、UP、稍后再看、分享、不感兴趣、下载。
- 卡片右上角“⋮”按钮可见。
- 全屏播放器设置中可见“视频数据”和“投屏（DLNA）”入口。
- 视频数据面板实际显示 1920x1080、AVC、4.09 Mbps、缓冲、解码器、音轨、CDN 等信息。
- 构建和单元测试通过，无 `FATAL EXCEPTION`。
