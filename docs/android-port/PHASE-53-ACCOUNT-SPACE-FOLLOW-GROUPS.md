# Android 移植阶段五十三：个人空间、粉丝列表与关注分组

## 已有能力确认

- “我的”页已有头像、昵称、签名、等级、经验、动态/关注/粉丝/硬币统计
- 已有历史、投稿、收藏夹、追番、追剧、稍后再看、最近点赞页签
- 收藏夹详情已支持打开视频和单个取消收藏
- 稍后再看列表已存在
- 观看历史已支持分页、删除和继续播放
- 全屏/内嵌播放器已接入云端进度恢复与上报
- 多账号切换、添加账号、退出、账号状态持久化已存在

## 本次新增

### 粉丝列表

- 新增 `x/relation/fans` 分页接口
- `FollowingListActivity` 支持两种模式：
  - 关注列表
  - 粉丝列表
- 用户浮层“粉丝”按钮接入粉丝列表
- “我的”页关注/粉丝统计数字可点击进入对应列表

### 关注分组

- 新增 `x/relation/tags` 分组列表接口
- 新增 `x/relation/tag` 按分组获取关注列表接口
- 关注列表顶部增加“分组：全部”按钮
- 可选择“全部”或任意关注分组，按分组加载关注 UP
