# Android 移植阶段十九：详情页 Tab 数量与分集命名

> 个人自用、仅技术验证，不对外分发。

## 目标

对齐 wiliwili 视频详情页右侧 Tab：

```text
评论(数量)  分集(数量)  推荐(数量)  投稿(数量)
```

## 实现

- 将“合集”重命名为“分集”
- 评论数量：从评论接口第一页的 `totalCount` 回传
- 分集数量：优先使用 UGC 合集数量，否则使用分P数量
- 推荐数量：使用相关推荐列表实际加载数量
- 投稿数量：后台预取 UP 主投稿第一页，读取分页 `total`
- 大数字使用 `万 / 亿` 缩写，避免 Tab 被挤压
- 详情页右侧改为自定义四等分 Tab 栏：
  - 四个 Tab 固定单行
  - 选中项显示粉色下划线
  - 支持点击和手柄 LB/RB 切换
  - 窄栏模式下仍保持四个标签可见

## 验证

实测详情页显示：

```text
评论(434)  分集(11)  推荐(40)  投稿(310)
```

- 四个标签均保持单行
- 点击“分集”后右侧面板收窄，四个带数量标签仍完整显示
- 手柄 RB 可从评论切到分集
- 无 `FATAL EXCEPTION`
