# Android 移植阶段三十四：移除全屏播放器“视频详情页”和“上传广告片段”按钮

> 个人自用、仅技术验证，不对外分发。

## 两个按钮原功能

- 列表图标：`btn_detail`，功能为“视频详情页”，点击后从全屏播放器进入视频详情页。
- 盾牌播放图标：`btn_sponsor_submit`，功能为“上传广告片段”，属于 SponsorBlock 广告片段提交入口。

## 修改内容

- 全屏播放器 OSD 不再显示这两个按钮。
- 从默认 OSD 按钮集合中移除。
- 从设置页“OSD 按钮显示”可选项中移除。
- 从设置页“下键呼出 OSD 后焦点”可选项中移除。
- 播放器代码中强制隐藏这两个控件，避免旧配置重新显示。
- 保留“列表/推荐面板”按钮（向下箭头），该按钮不是本次要求删除的列表图标按钮。

## 验证

- 全屏播放器底栏已不再显示“视频详情页”和“上传广告片段”按钮。
- 其余播放、下一集、字幕、弹幕、评论、UP、列表、设置、关闭按钮正常。
- `assembleDebug` 和 `testDebugUnitTest` 通过。
- 无 `FATAL EXCEPTION`。

## 构建

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```
