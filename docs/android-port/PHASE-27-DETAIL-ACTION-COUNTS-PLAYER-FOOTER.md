# Android 移植阶段二十七：详情页操作计数与播放器控制栏

> 个人自用、仅技术验证，不对外分发。

## 操作按钮计数

- 点赞按钮下方显示点赞总数
- 投币按钮下方显示投币总数
- 收藏按钮下方显示收藏总数
- 评论按钮下方显示评论总数
- 新增分享按钮，并显示分享总数
- 计数来自视频详情接口 `stat` 字段：
  - `like`
  - `coin`
  - `favorite`
  - `reply`
  - `share`
- 大数字使用 `万 / 亿` 缩写
- 分享按钮会打开系统分享面板，分享视频标题和链接

## 详情页底部控制栏

详情页底部改为播放器快捷操作：

```text
画质 / 快退 / 快进 / B 返回 / A 全屏
```

- `画质`：打开画质选择，保存为默认播放画质
- `快退`：从当前视频起点/偏移进入播放器
- `快进`：从 10 秒位置进入播放器
- `B 返回`：返回上一级
- `A 全屏`：进入全屏播放器

## 手柄映射

- `LA / RA`（L1 / R1）：切换右侧 Tab
- `LT / RT`（L2 / R2）：快退 / 快进
- 菜单键 / Start：打开画质选择
- `B`：返回
- `A`：进入全屏播放器

## 验证

- 操作按钮下方显示真实数量
- 分享按钮正常显示图标与数量
- 底部显示 `画质 / 快退 / 快进 / B 返回 / A 全屏`
- 菜单键成功打开画质选择弹窗
- A 键成功进入 `PlayerActivity`
- 无 `FATAL EXCEPTION`
