# 比亚迪车机兼容性静态评估

> 结论：**静态条件基本兼容，但尚未在真实比亚迪车机实机验证。**

## APK 基础信息

- minSdk：21
- targetSdk：36
- 包名：`cn.xfangfang.wiliwili.poc`
- 屏幕方向：强制横屏
- 触摸屏：`required=false`
- Leanback：`required=false`
- 已打包四套 ABI 的 `libijkplayer.so`，默认播放器为 ExoPlayer，失败时自动切 IjkPlayer 软解
- 无 Google Play Services / Firebase 依赖

## 有利条件

1. 比亚迪车机通常是横屏，符合本项目的横屏要求。
2. 不强制要求触摸屏，支持方向键/遥控器焦点。
3. 不依赖 Google 服务，网络使用 OkHttp。
4. 安装包没有 ABI 限制，纯 JVM/AndroidX 主体可在 arm64 车机运行。
5. 默认 ExoPlayer 使用系统 MediaCodec，车机有 H.264 硬解时可直接播放。
6. 支持 USB/本地 APK 安装（需车机允许未知来源）。

## 需要实机确认的风险

| 项目 | 风险 | 验证方法 |
|---|---|---|
| 安装权限 | 车机可能禁止第三方 APK | 打开开发者模式/允许未知来源后安装 |
| 方向盘/中控按键 | 厂商可能使用私有键值 | `adb shell getevent -l` 看实际 keycode |
| 分辨率/DPI | 1280x720 或超宽屏可能布局偏移 | 实机截图检查首页、设置、播放器 OSD |
| 硬件解码 | 低端车机可能缺少 H.264 硬解或性能不足 | 播放 1080P/720P，检查是否触发 IjkPlayer 兜底 |
| 音频输出 | 车机音频焦点/通道策略不同 | 播放视频、切后台、导航播报时检查 |
| 网络 | 车机仅支持热点或限制 HTTPS | 测试登录、搜索、视频播放 |
| 存储 | 下载目录可能受限 | 测试缓存和导出/下载 |
| 后台 | 车机可能强制杀后台 | 播放中切到桌面再返回 |
| IjkPlayer | 原生库已内置，需验证车机 CPU/音频焦点 | 播放 720P/1080P，检查发热、导航播报抢占 |
| 签名 | debug 签名安装与升级 | 覆盖安装 0.10/0.11 验证 |

## 建议实机测试顺序

1. 安装 APK，确认启动无 `FATAL EXCEPTION`。
2. 首页、搜索、动态、我的、消息中心、设置逐页打开。
3. 视频详情内嵌播放 30 秒。
4. 全屏播放、方向键 seek、缩略图预览、音量。
5. 方向盘/中控方向键和 OK/返回键检查焦点。
6. 播放中切后台、导航播报、切回前台。
7. 下载/缓存/退出重进。

## 结论

按包结构、SDK、横屏方向和输入方式判断，**大概率可以在主流比亚迪 DiLink 车机安装运行**，但最终必须用真实车机验证安装权限、按键 keycode、硬解和音频焦点。
