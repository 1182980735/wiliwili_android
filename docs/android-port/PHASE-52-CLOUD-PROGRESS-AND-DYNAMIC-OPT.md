# Android 移植阶段五十二：云端进度同步与动态/专栏优化

## 云端播放进度

### 内嵌播放器恢复

- 起播时读取 `VideoPlayStream.resume`。
- 遵守设置中的“自动跳到上次播放位置”。
- 校验 `lastCid`，避免多 P 视频错误跳到其他分 P。
- 仅在有效区间内恢复：开头 5 秒以内、结尾 10 秒以内不跳转。
- 恢复时提示“已从上次进度继续”。

### 进度上报

- 登录且存在 `bili_jct` 时启用。
- 播放中每约 15 秒上报一次 `x/v2/history/report`。
- 暂停、拖动进度、切换画质、切后台、释放播放器时立即上报。
- 上报失败只写日志，不影响本地播放。

## 动态页优化

- 专栏使用综合动态流，保留纯文字、图文、转发、文章动态。
- 过滤 AV、PGC、直播回放、课程、合集等视频类型。
- 专栏加载更多时跳过“过滤后为空”的页，避免滚动到底部却没有内容。
- 视频页仍只使用视频流接口。

## 专栏优化

- 专栏卡片保留封面、正文摘要、无图文字兜底。
- 详情使用 BiliClient 动态详情接口原生渲染，不加载 WebView。
- 支持作者、时间、正文、视频信息、点赞/评论。
- 支持多张原图、等比完整显示和上下滚动。
- 移除重复顶部标题，同时保留正文标题。

## 验证

- `assembleDebug` 通过
- `testDebugUnitTest` 通过
- 动态专栏实测：纯文字、图文、转发、文章均显示，视频类已过滤
- 原生详情弹窗实测正常
- 无 FATAL / ANR
