# wiliwili Android 0.10

## 版本

- versionName: `0.10`
- versionCode: `10`
- package: `cn.xfangfang.wiliwili.poc`
- 构建类型：debug（固定 debug 签名，可覆盖安装）

## 主要功能

- wiliwili 风格主页、搜索、动态、我的、视频详情和消息中心
- 首页直播子 Tab：关注 / 推荐 / 分区
- 视频卡片长按操作菜单
- 视频详情内嵌播放器
- DASH MPD + CDN failover 内嵌播放
- 内嵌播放切全屏继承当前进度
- 播放器 OSD：音量、倍速、弹幕开关、设置、播放列表、视频数据
- 详情页右侧评论/分集/推荐/投稿
- 消息中心聊天历史、图片/表情渲染、已读同步、文本发送
- 全屏播放器视频数据、DLNA 设备发现
- 软件解码器按策略处理，避免偶发绿屏
