# Android 移植阶段二十八：详情页内嵌播放器

> 个人自用、仅技术验证，不对外分发。

## 目标

对齐 wiliwili 视频详情页左侧内嵌播放器：

- 视频直接在详情页播放
- 进度条与时间
- 播放 / 暂停
- 弹幕层
- 画质选择
- 全屏入口

## 实现

- 详情页头部新增：
  - `PlayerView`
  - `DanmakuView`
  - 加载指示器
  - 内嵌播放控制栏
- 详情数据加载完成后自动请求播放流并开始播放
- 使用 Media3 ExoPlayer 播放 B 站渐进流
- 使用自定义 `RenderersFactory`：
  - 关闭异步 MediaCodec 队列
  - 开启解码器回退
  - 规避部分设备绿屏/首帧异常
- 内嵌播放默认限制到 720P AVC，优先保证兼容性
- 播放控制：
  - 播放 / 暂停
  - 拖动进度条 seek
  - 当前时间 / 总时长
  - 画质选择并保留播放位置
  - 全屏进入 `PlayerActivity`
- 弹幕：
  - 复用现有 `DanmakuView`
  - 读取弹幕开关、透明度、字号、速度、区域等偏好
  - 首次加载限制为前 2 个弹幕分片，避免占满视频带宽
- 生命周期：
  - 页面暂停时暂停播放
  - 页面销毁时释放播放器
  - 全屏跳转时暂停内嵌播放

## 验证

- 详情页视频自动在左侧播放
- 视频画面正常出画，无绿屏
- 进度与时间持续前进
- 暂停 / 继续可用
- 进度条 seek 可用
- 画质弹窗可打开并重新加载
- `全屏` 可进入 `PlayerActivity`
- 无 `FATAL EXCEPTION`
