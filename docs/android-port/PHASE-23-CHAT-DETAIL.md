# Android 移植阶段二十三：消息中心聊天详情

> 个人自用、仅技术验证，不对外分发。

## 目标

点击消息中心“聊天列表”中的会话可以进入聊天详情，不再只提示“聊天详情暂未接入”。

## 实现

- `MessageCenterItem` 新增 `talkerId`
- 新增聊天消息模型 `ChatMessageItem`
- 新增接口 `fetch_session_msgs` 拉取会话历史消息
- 消息中心增加聊天详情覆盖层：
  - 顶部返回按钮和聊天对象昵称
  - 聊天气泡列表
  - 对方消息左对齐，自己消息右对齐
  - 自动滚动到最新消息
- 系统返回键优先关闭聊天详情，回到聊天列表
- 关闭消息中心时取消聊天加载任务

## 消息内容

支持解析：

- 文本消息
- 图片消息占位 `[图片]`
- 撤回消息占位 `[撤回消息]`
- 视频分享消息标题

## 验证

实测聊天会话：

```text
chat messages talker=14003017 count=50
```

- 点击聊天列表首项进入聊天详情
- 显示真实历史消息
- 返回键回到消息中心列表
- 遮罩和原页面背景保持正常
- 无 `FATAL EXCEPTION`
