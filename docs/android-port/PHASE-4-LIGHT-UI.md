# Android 移植阶段四：向 wiliwili 参考截图对齐

> 个人自用、仅技术验证，不对外分发。

## 参考目标

根据用户提供的 wiliwili 首页、动态页、个人主页截图，重新对齐：
浅色主题、三入口侧栏、首页搜索框、底部手柄提示栏、动态双栏、我的用户卡与内容 Tab。

## 1. 浅色主题

新增 `Theme.Blbl.Base.WiliWiliLight` 并设为默认主题：

- 页面背景 `#F5F6F7`
- 卡片表面 `#FFFFFF`
- 主文字 `#18191C`
- 次级文字 `#9499A0`
- 主色 `#FF6699`
- 分隔线 `#E3E5E7`
- 底部提示栏 `#E9EAEC`
- 浅色状态栏/导航栏图标
- 新增浅色焦点 selector，未聚焦时不显示边框，聚焦时显示粉色描边

播放器继续使用深色主题，避免媒体播放时受到浅色背景干扰。

## 2. 主壳对齐

- 左侧只保留首页、动态、我的三个一级入口
- 隐藏侧栏用户头像，登录入口保留在我的页和设置页
- 侧栏底部新增消息按钮和设置按钮
- 新增底部控制器提示栏：电池状态、时钟、`Y 搜索 / B 返回 / A 确定`
- 首页右上角新增圆角搜索框，点击进入搜索页
- 支持键盘/手柄 `Y` 键从主界面直接打开搜索

## 3. 首页对齐

- 五个顶部 Tab：直播、推荐、热门、追番、影视
- 搜索框位于顶部 Tab 右侧
- 视频卡片改为透明背景，去掉粉色标题竖条
- 保留封面、时长/统计胶囊、两行标题、UP 主与日期
- 标题改为常规字重，更接近参考截图

## 4. 动态页对齐

- 左侧面板宽度调整为 280dp
- 移除“关注 UP”标题栏
- 第一项改为粉色圆形图标 + “全部动态”
- 选中项使用粉色头像图标/粉色文字，不再整行铺粉色背景
- 右侧保留“视频 / 综合”Tab 和三列视频网格
- 保留关注列表、分页、刷新、返回和焦点逻辑

## 5. 我的页对齐

- 用户卡改为白色浅色表面
- 头像、昵称、个人签名、动态/关注/粉丝/硬币统计
- 个人签名使用 B 站 nav 接口的 `sign`，为空时显示“这个人很神秘，什么都没有写”
- 隐藏用户卡内的等级/UID 辅助行，贴近参考截图的信息层级
- Tab 文案调整为：历史记录、我的收藏、我的追番、我的追剧、稍后再看、最近点赞
- 历史/收藏等内容网格继续使用统一视频卡片

## 6. 验证

- `./gradlew assembleDebug`：通过
- `./gradlew testDebugUnitTest`：通过
- Android 12、2560×1440 强制横屏真机/模拟器验证：
  - 首页浅色主题、侧栏三入口、顶部搜索框、底部提示栏正常
  - 点击顶部搜索框可进入搜索页
  - 动态页已登录态双栏内容正常
  - 我的页已登录用户卡、统计、历史与收藏 Tab 正常
  - 无 `FATAL EXCEPTION`

## 7. 与参考截图仍存在差异

- 参考图是桌面端窗口，带 macOS 标题栏；Android 版无法复刻窗口装饰。
- 参考图我的页第三个 Tab 是“我的订阅”；当前工程没有订阅数据接口，仍保留“最近点赞”。
- 侧栏没有复刻参考图中的登录头像入口，登录/账号切换改由我的页和设置页承担。
- 视频卡片字段来自 blbl 数据模型，UP 图标和日期格式与 wiliwili 原始实现仍有细微差异。
