# Android 移植阶段十二：详情页比例调整

> 个人自用、仅技术验证，不对外分发。

## 调整内容

### 右侧面板

- 评论 Tab：保持原来的 66% / 34% 左右分栏比例
- 合集 / 推荐 / 投稿 Tab：右侧窗口宽度减半
- 分栏参考线从 0.66 切换到 0.83
- 右侧四个 Tab 使用固定紧凑布局，宽度减半后仍全部可见、可点击
- 评论列表布局不变

### 左侧视频下方信息区

以下内容尺寸整体缩小到约一半：

- 标题
- 播放量/点赞等元信息
- UP 主卡片与头像
- 简介区域
- 标签 Chip
- 播放、点赞、投币、收藏、评论按钮
- 分P/合集标题与按钮

### 视频区域

- 减少详情卡片内边距和下方信息高度
- 合集 / 推荐 / 投稿 Tab 下，左侧宽度由约 66% 扩大到约 83%
- 16:9 视频预览随左侧宽度放大
- 中央播放按钮同步缩小，避免遮挡过多画面

## 验证

- 评论 Tab：右栏保持原宽度
- 推荐 Tab：右栏减半，视频明显放大
- 四个 Tab 在窄右栏中仍可见
- 点击视频预览仍可进入播放器
- 页面无崩溃

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```
