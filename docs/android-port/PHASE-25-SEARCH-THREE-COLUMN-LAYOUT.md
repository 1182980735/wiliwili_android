# Android 移植阶段二十五：搜索页三列布局与热门搜索标记

> 个人自用、仅技术验证，不对外分发。

## 目标

对齐 wiliwili 搜索初始页：

- 左侧列：搜索框和键盘
- 中间列：热门搜索
- 右侧列：历史记录
- 右侧顶部悬浮关闭按钮

## 实现

- 搜索框从页面顶部通栏移入左侧列
- 左侧列下方保留搜索键盘、清空、后退和搜索按钮
- 中间列改为热门搜索
- 右侧列改为历史记录
- 右上角新增悬浮圆形关闭按钮，点击返回首页
- 搜索结果页显示时隐藏悬浮关闭按钮

## 热门搜索

- API 从 `search/square` 的 `trending.list` 解析：
  - `keyword`
  - `show_name`
  - `icon`
- 列表显示 1-9 排名
- 前三名使用主题粉色强调
- `icon` 支持图片 URL 或文本标记
- 实际显示“新 / 热 / 独家”等 B 站标记

## 验证

- 左侧搜索框和键盘正常
- 中间热门搜索显示 1-9 排名
- 热门搜索标记显示正常
- 右侧历史记录正常
- 点击热门搜索可进入结果页
- 右上角关闭按钮返回首页
- 搜索结果页布局正常
- 无 `FATAL EXCEPTION`
