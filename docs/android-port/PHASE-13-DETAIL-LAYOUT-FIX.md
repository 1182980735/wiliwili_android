# Android 移植阶段十三：详情页变形修复

> 个人自用、仅技术验证，不对外分发。

## 修复内容

### 左侧详情区

- `SwipeRefreshLayout` 改为完整高度的详情面板
- 增加左右上下外边距和圆角背景
- 详情头图背景改为透明，与整块左侧面板融合
- 消除下方灰色断层和大块不连续背景
- 视频预览、标题、UP 主、简介和操作区保持在同一个左侧面板内

### 右侧面板

- 评论 Tab 保持 66% / 34% 分栏
- 合集 / 推荐 / 投稿 Tab 调整为 80% / 20% 分栏
- 比上一版 83% / 17% 稍宽，避免视频卡片和 Tab 被压扁
- 右侧视频卡片恢复可读宽度

### Tab 字体

- 新增专用 `TextAppearance.Blbl.DetailTab`
- “评论 / 合集 / 推荐 / 投稿”统一固定为 14sp
- 不再因选中状态或窄栏布局出现字号不一致

## 验证

- 评论页左侧为完整白色面板，无灰色断层
- 推荐页左侧视频放大，右侧为可读窄栏
- 四个 Tab 字号和高度一致
- 四个 Tab 在窄栏下全部可见、可点击
- 视频预览与播放器入口正常
- 无崩溃

## 构建

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

均通过。
