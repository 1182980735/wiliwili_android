# Android 移植阶段四十五：左侧栏消息/设置图标尺寸对齐

> 个人自用、仅技术验证，不对外分发。

## 问题

左侧栏底部“消息中心”和“设置”两个按钮的视觉大小不一致，消息图标明显偏大。

## 原因

两个 MaterialCardView 容器都是 34dp，但内部矢量图标的路径占比不同：

- 消息图标路径几乎铺满 20dp 画布
- 设置图标路径在 32dp 画布中只占约 20dp

在 `fitCenter` 下同时缩放到 25dp 内容区后，设置图标视觉上更小。

## 修复

- 消息图标显式使用 22dp 显示框，视觉约 19.8dp。
- 设置卡片内边距改为 0，设置图标显式使用 34dp 显示框，视觉约 21.25dp。
- 两者都居中对齐，保持原有 34dp 按钮点击区域。
- 未使用 Wiliwili 的 BPX 设置矢量源，因为其中路径格式在 Android 12 上不兼容，会导致启动崩溃。

## 验证

- 消息和设置图标视觉尺寸基本一致。
- 点击区域仍为 34dp。
- 启动无崩溃、无 `FATAL EXCEPTION`。
- `assembleDebug` 和 `testDebugUnitTest` 通过。
