# Android 移植阶段五十：内嵌播放器快捷按钮自动隐藏

## 目标

窗口模式下，红框内的快捷按钮默认隐藏；点击播放器显示；5 秒无操作自动隐藏。

涉及按钮：

- 音量
- 倍速
- 弹幕
- 设置
- 播放列表
- 视频数据

## 实现

- `inline_quick_actions` 初始化保持 `GONE`。
- `prepare()` 开始播放时显式隐藏，避免复用到旧可见状态。
- `PlayerView`、Ijk `TextureView`、封面区域增加点击监听：
  - 点击后显示 `inline_quick_actions`
  - 重新计时 5 秒
- 快捷按钮点击时也会重置 5 秒计时。
- 5 秒后通过协程自动切回 `GONE`。
- 遥控器 OSD 键仍可手动切换快捷按钮行。
- 底部播放/进度/画质/全屏控制不在此次隐藏范围内。

## 验证

- 默认状态：快捷按钮隐藏
- 点击播放器：快捷按钮显示
- 5 秒不操作：快捷按钮自动隐藏
- `assembleDebug` / `testDebugUnitTest` 通过
- 无新的 FATAL/ANR
