# Android 移植阶段十四：左侧视频填满与信息区下移

> 个人自用、仅技术验证，不对外分发。

## 目标

解决左侧视频预览偏小、视频下方信息区上方留白过多、底部出现大块空白的问题。

## 实现

- 详情页左侧视频容器高度不再固定为 16:9 比例
- `VideoDetailActivity` 在左侧面板完成布局后，动态计算可用高度
- 视频预览高度设置为左侧可用高度的 62%
- `VideoDetailHeaderAdapter` 支持运行时设置视频容器高度
- 视频下方标题、UP 主、简介、标签和操作按钮自然下移
- 信息区靠近屏幕底部，减少视频与信息区之间的空白
- 封面使用 `centerCrop` 填充容器，避免出现额外黑边或留白

## 结果

- 评论 Tab：视频明显放大，信息区贴近底部
- 推荐 / 合集 / 投稿 Tab：左侧视频继续占满上方，右侧保持窄栏
- 四个 Tab 仍保持统一 14sp 字号
- 点击视频预览可正常进入播放器
- 播放器首帧正常输出
