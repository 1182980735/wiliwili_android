# wiliwili Android 0.24

## 版本

- versionName: `0.24`
- versionCode: `24`
- package: `com.anhuihl.wiliwili.android`
- 应用名: `wiliwili_A`
- 启动图标: 粉色全幅自适应图标 + 白色 wiliWili 标志
- 构建类型：debug（固定 debug 签名，可覆盖安装 0.23）

## 0.24 版本

- 全屏播放器支持 Android Picture-in-Picture
- Home 键进入 PiP 后继续播放
- PiP 退出恢复播放器界面
- Home/画中画期间跳过立即暂停
- 当前后台音频采用 Activity 生命周期保持，后续可继续增加前台服务和 MediaSession
- 保留 0.23 公开用户空间关注/粉丝入口

- 为 0.24 画中画/后台音频做版本边界

## 播放器

- 内嵌播放器抽成 `BlblPlayerEngine` 接口
- 默认 ExoPlayer 硬件解码优先
- ExoPlayer 报错或连续卡顿后自动切 IjkPlayer 同画质软解
- 四套 ABI 的 `libijkplayer.so` 已打进 APK
- 取消自动降 360P/480P，恢复尊重用户默认画质
- ExoPlayer / IjkPlayer 增加音频焦点管理
- 内嵌播放器快捷按钮默认隐藏，点击显示，5 秒无操作自动隐藏

## 动态页

- 专栏从单列列表改为卡片网格
- 专栏使用综合非视频动态流，保留纯文字、图文、转发、文章动态
- 过滤 AV、PGC、直播回放、课程、合集等视频类型
- 纯文字动态读取 `module_desc.text`，卡片显示 UP 主正文
- 无封面卡片显示正文摘要，不再空白
- 详情弹窗改为 BiliClient 动态详情接口 + 原生渲染
- 不再用 WebView 请求 B 站 H5，避免 412 风控和 App 推广层
- 详情图片按原比例完整显示，支持多图和上下滚动
- 长图加载完成后动态计算高度，避免固定高度裁切
- 动态详情弹窗移除重复的顶部标题，只保留正文标题
- 修复纯文字动态因标题与正文相同而正文标题消失的问题

## 云端进度与动态优化

- 内嵌播放器支持云端进度恢复和定期上报
- 暂停、拖动、切后台、释放时立即上报进度
- 专栏保留全部非视频动态，过滤视频类型
- 专栏加载更多自动跳过过滤后为空的页
- 动态页新增全部 / 视频 / 专栏 / 图文 / 转发五个页签
- 切换动态页签不再自动打开第一条动态
- 专栏详情支持复制正文、字号调节、夜间模式
- 专栏图片支持点击缩放和保存到相册
- 新增粉丝列表，用户浮层和空间统计可进入
- 关注列表支持按关注分组筛选
- 视频详情页新增下载按钮，复用播放器下载链路
- 侧边栏新增分类入口，固定在首页和动态之间
- 详情页操作按钮改为低饱和雾青色，降低视觉突兀感
- 详情页信息条和简介区域取消背景色
- 动态详情原生渲染、多图完整显示、上下滚动
