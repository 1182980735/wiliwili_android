# Android 移植阶段十五：详情页按钮与视频黑底修复

> 个人自用、仅技术验证，不对外分发。

## 问题

- 左下角播放/点赞/投币/收藏/评论按钮被压得太小
- 主播放按钮高度不足，显示成扁长条
- 视频未播放时预览区没有黑色背景

## 修复

### 操作按钮

- 主播放按钮高度从 28dp 调整为 40dp
- 主播放按钮最小宽度从 72dp 调整为 96dp
- 主播放文字从 10sp 调整为 13sp
- 点赞/投币/收藏/评论按钮高度从 28dp 调整为 40dp
- 操作按钮宽度从 36dp 调整为 48dp
- 图标从 14dp 调整为 18dp
- 标签文字从 7sp 调整为 9sp
- 按钮圆角调整为 10dp，主播放按钮改为 20dp 圆角

### 视频预览

- 视频容器背景改为纯黑色
- 封面 `scaleType` 从 `centerCrop` 改为 `fitCenter`
- 未播放时封面完整居中显示，上下自然出现黑色留边
- 不再用裁切填满整个容器

## 验证

- 播放按钮比例正常，不再扁长
- 点赞/投币/收藏/评论按钮文字与图标可读
- 视频未播放时背景为黑色
- 评论列表宽度和 Tab 字号保持正常
- 点击视频预览仍可进入播放器

## 构建

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

均通过。

## 追加修正

- 移除了 `VideoDetailHeaderAdapter` 中强制把普通视频容器设为 `480dp + 16:9` 的旧逻辑
- 普通视频容器改为铺满左侧面板宽度
- 视频高度继续使用左侧可用高度的 62%
- 封面改为 `centerCrop`，完整填满视频容器
- 容器仍保留黑色背景，仅当封面比例与容器不一致或加载失败时显示
- 竖版番剧海报仍保留原来的固定竖版宽度逻辑
