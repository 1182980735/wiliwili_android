# Android 移植阶段二十九：内嵌播放器回归测试与修复

> 个人自用、仅技术验证，不对外分发。

## 测试方法

随机选择 10 个视频：

1. 从首页点开详情页
2. 等待内嵌播放器自动播放
3. 抓取播放画面
4. 拖动进度条到接近结尾
5. 再次抓取画面
6. 检查截图视频区域的绿屏比例、纯黑比例
7. 检查 `FATAL EXCEPTION`

## 首轮结果

720P 内嵌播放测试发现：

- 5/10 个视频出现大面积绿色画面
- 部分视频在 4~7 秒后进入持续缓冲
- 部分绿屏来源于首帧未渲染时 SurfaceView 直接显示绿色占位
- 无应用崩溃

## 修复

- 内嵌播放请求限制为 480P + AVC/H.264，提高模拟器/低端设备兼容性
- PlayerView 改用 TextureView，避免 SurfaceView 覆盖首帧封面兜底
- 首帧渲染前显示封面、加载指示器和控制层，不再暴露绿色 Surface
- 监听 `onRenderedFirstFrame`，首帧完成后才隐藏封面
- 增加首帧超时重试：
  - 8 秒未渲染首帧时自动切换到下一个 CDN 地址
  - 循环尝试播放源提供的 CDN 候选
- 进度条、播放/暂停、画质、全屏继续复用现有逻辑

## 修复后验证

- 抽查样本视频正常出画
- 绿色像素占比从约 58% 降至 0%~0.18%
- 黑色占比保持在普通暗场景范围
- 播放时间正常推进
- 未出现 `FATAL EXCEPTION`

## 已知环境限制

模拟器网络访问 B 站 CDN 较慢时仍可能出现缓冲等待；此时会显示封面和加载层，而不是绿屏或花屏。
