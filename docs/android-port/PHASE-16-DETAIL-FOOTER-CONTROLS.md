# Android 移植阶段十六：视频详情页底部控制栏

> 个人自用、仅技术验证，不对外分发。

## 功能

将首页底部 X/Y/A/B 控制栏移植到视频详情页：

| 按键 | 详情页行为 |
| --- | --- |
| X 刷新 | 刷新当前焦点所在窗口的内容 |
| Y 搜索 | 打开搜索页，返回后仍回到原视频详情页 |
| B 返回 | 返回当前窗口的上一个状态，不关闭视频详情页 |
| A 确定 | 点击当前焦点可交互内容 |

## 焦点窗口刷新

根据当前焦点位置和右侧 Tab 决定刷新目标：

- 左侧详情/视频区域：重新加载视频详情和推荐
- 评论窗口：重新加载评论根列表
- 合集窗口：重新提交分P/合集卡片
- 推荐窗口：重新请求相关推荐视频
- 投稿窗口：重新加载 UP 主投稿

## 返回逻辑

B 返回按以下顺序处理：

1. 评论回复线程打开时，返回评论根列表
2. 评论图片查看器打开时，关闭图片查看器
3. 当前不是评论 Tab 时，切回评论 Tab
4. 焦点在右侧评论/推荐窗口时，回到左侧播放区域
5. 已在详情页默认状态时保持详情页打开，不直接关闭 Activity

系统返回键仍保留原有的 Activity 返回行为，不受 B 键逻辑影响。

## 搜索入口

- 详情页 Y 键或“Y 搜索”按钮会启动搜索页面
- 搜索页返回后仍可回到原视频详情页

## 硬件按键

`VideoDetailActivity` 同时支持：

- `KEYCODE_X` / `KEYCODE_BUTTON_X`
- `KEYCODE_Y` / `KEYCODE_BUTTON_Y`
- `KEYCODE_A` / `KEYCODE_BUTTON_A`
- `KEYCODE_B` / `KEYCODE_BUTTON_B`

输入框编辑状态下不拦截字母键。

## 验证

- 视频详情页底部显示 X/Y/A/B 控制栏
- X 刷新触发详情或当前右侧窗口刷新
- Y 打开搜索页
- B 不关闭视频详情页
- A 对焦点项执行点击
- 底部控制栏与左右面板不重叠
- 无崩溃
